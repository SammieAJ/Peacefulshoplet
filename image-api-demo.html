📚 How It Works

1. API Call: When you click a category, JavaScript makes a request to Pexels API

2. Search Query: API searches for images matching your category (e.g., "african fashion gown")

3. Response: Pexels returns 12 high-quality fashion photos

4. Display: Images are displayed in a beautiful grid

5. Integration: In your actual store, these become products with prices and details!
